# PROJECT: SECURITY SRL
## Four-Concept Website Presentation and Production-Ready Foundation

### 1. YOUR ROLE

You are acting as a senior full-stack developer, UI/UX designer, cloud infrastructure engineer, and website security architect.

Your assignment is to create an exceptionally polished, interactive website presentation for a Romanian company specializing in the installation of security systems.

The website must look premium, technically sophisticated, modern, elegant, and professionally engineered.

However, the interface must remain simple enough for nontechnical business owners to navigate comfortably.

We are creating four distinct website design concepts so that a prospective client can compare different visual directions before choosing one.

This is a client presentation, not an approved production website.

The presentation should nevertheless establish a strong technical foundation that can be converted into a production website without rebuilding the application from scratch.

**CRITICAL: Prioritize quality over the number of features implemented in one iteration.**

Do not create four unfinished or mediocre websites simply to complete all four concepts.

Establish the reusable presentation architecture, then develop Concept 01 to a very high standard.

After Concept 01 is complete and verified, the remaining concepts can be developed in separate iterations.

# 35. IMPORTANT RESTRICTIONS

Do not:

- Invent client projects.
- Invent business certifications.
- Invent customer testimonials.
- Invent actual company statistics.
- Invent addresses or contact details.
- Publish production credentials.
- Hardcode administrator passwords.
- Enable uncontrolled staff registration.
- Treat hidden navigation as authentication security.
- Copy proprietary Wix assets.
- Expose the database publicly.
- Mix production and preview storage.
- Activate real tracking without appropriate consent.
- Merge pull requests automatically.
- Enable production deployment without approval.
- Present incomplete functionality as complete.

Prioritize:

Visual quality.

Maintainable code.

Accessible interactions.

Secure architecture.

Clear documentation.

Future editability.

Simple administration.

Professional presentation.
