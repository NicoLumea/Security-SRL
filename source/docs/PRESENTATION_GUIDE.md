# Client presentation guide

1. Open the private preview root, not a production URL. Confirm access protection in a fresh browser.
2. Explain that Security SRL is a working identity and this is a design proposal. Show the four directions; only Sentinel is available in this iteration.
3. Explore Sentinel's homepage. Discuss the dark architectural photography, controlled gold, clear type and prominent portfolio.
4. Open services and a project example. Explain that these are proposed categories and stock-photo scenarios, not completed installations.
5. Switch RO/EN while on a project to demonstrate corresponding localized pages.
6. Show the mobile menu, search and category filters. Mobile featured cards can be swiped; rotation is opt-in and can be paused.
7. Demonstrate the contact form using fictional data only. It validates locally and explicitly confirms that nothing was sent/saved.
8. Open cookie preferences. No analytics or advertising exists, regardless of choices. Legal pages are presentation notices, not completed legal review.
9. Show the discreet staff link and explain it is intentionally inactive until the authentication phase.
10. Record feedback on visual direction, wording, logo, real service list, portfolio permissions, contact details and video preference before implementing other concepts.

## Review checklist

- Four cards; unavailable concepts do not navigate.
- Root is the neutral gallery; website navigation is separate from concept controls.
- No false certifications, statistics, testimonials, clients, addresses or projects.
- Keyboard focus and reduced-motion fallback remain available.
- All expected language-specific routes and links resolve.
- Browser responsive testing and CI results reviewed, including limitations in VERIFICATION.md.
- No production deployment or automatic PR merge.
